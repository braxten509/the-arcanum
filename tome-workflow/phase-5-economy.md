# Phase 5 — Economy pass

Read **§2 [economy]**. Sum fixed face-value credits (exercise points + freestyle
rewards). Treat intrusion bounties as repeatable bonus income, never as one guaranteed
payout per tier; duel coin is also a late trickle. Set ranks, prices, rewards, and
hint/oracle costs so mid-course purchases and late-game trophies both exist. Land the
top rank within about 15% of fixed face value; combos, S ranks, and successful defenses
can bridge a modest positive gap, while a large negative gap ends progression too early.

→ **Produce:** a balanced `[economy]`.
